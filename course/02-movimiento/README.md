# Bloque 02 - Movimiento

Estado: `PLANIFICADO`. Lecciones 12-20 de la [matriz](../../docs/curriculum-matrix.md).

El bloque comenzará con un motor aislado y ruedas levantadas. No se presentará el programa completo de OSOYOO hasta comprender motor DC, Model Y, puente H, dirección, PWM, cuatro motores, orientación Mecanum y vectores.
