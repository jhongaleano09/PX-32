# Bitácora científica

Duplica [PLANTILLA.md](PLANTILLA.md) con un nombre como `2026-09-12-leccion-01.md`. La predicción se escribe antes del experimento; no se corrige después. Si fue distinta del resultado, eso no es “fallar”: es información.

Una entrada completa permite que otra persona sepa qué hardware, programa, condición y cambio produjeron el resultado.
