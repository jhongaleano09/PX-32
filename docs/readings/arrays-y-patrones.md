# Arrays y patrones espaciales

Un array guarda varios datos del mismo tipo bajo un nombre y permite recorrerlos mediante índices. En el tracker, las posiciones 0 a 4 representan A4 a A0. El patrón no debe confundirse con la posición física hasta verificar la orientación. Interpretar consiste en transformar lecturas crudas en una estimación y después en una orden; esas capas se prueban por separado.
