# Sonido, eco y distancia

El sonido es una onda mecánica. El HC-SR04 envía ultrasonido y mide la duración del eco. Como el pulso viaja hasta el objeto y vuelve, la distancia es velocidad por tiempo dividida entre dos. La aproximación 0,0343 cm/µs depende del ambiente. Superficies inclinadas, blandas, pequeñas o demasiado cercanas pueden devolver ecos débiles.
