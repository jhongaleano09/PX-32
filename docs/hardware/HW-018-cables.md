# HW-018 - Cables y jumpers

**Estado:** VERIFICADO_PDF como conjunto; cantidad total física pendiente.

## ¿Qué son y para qué sirven?

Transportan alimentación o señales entre módulos. El color ayuda a seguir rutas, pero no define eléctricamente un cable por sí solo.

## ¿Dónde están?

Entre Mega/shield, Model Y, sensores, servo, voltímetro y alimentación.

## Tipos documentados

- Dos cables de seis pines macho-hembra para Model Y.
- Cable de tres pines hembra-hembra.
- Cable de siete pines para tracker.
- Manojo de diez jumpers, del que se separan conductores.
- Cable de dos pines XH2.54/PnP entre Model Y y shield.

La nomenclatura varía entre listas del manual; comparar con conectores reales.

## Funcionamiento

Un conductor ofrece una ruta de baja resistencia. El aislamiento evita contacto no deseado. El conector sostiene y ordena terminales.

## Alimentación y seguridad

Nunca insertar o retirar con el sistema energizado. Sujetar la carcasa plástica, no tirar de los hilos, como advierte OSOYOO.

## Experimento mínimo

Clasificar por número de pines y tipo de extremos. Elegir un cable instalado y comprobar ambos extremos con el mapa, sin moverlo.

## Errores frecuentes

Confiar solo en color, desplazar un conector una posición, doblar terminales o usar un cable de carga sin datos para USB.
