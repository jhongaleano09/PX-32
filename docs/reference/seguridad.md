# Seguridad del laboratorio PX-32

## Cinco reglas críticas

1. Cablear solo con USB retirado, baterías retiradas o alimentación claramente apagada.
2. Un adulto se encarga de celdas 18650, cargador, potencia y cualquier cableado dudoso.
3. Las primeras pruebas de motores se hacen con ruedas levantadas y el área despejada.
4. Nunca cortocircuitar, perforar, calentar, aplastar ni usar una batería dañada.
5. Si aparece calor, olor, humo, chispa o movimiento inesperado: no investigar con la mano; cortar energía.

## Semáforo de actividades

| Nivel | Actividad | Regla |
|---|---|---|
| Verde | Lectura, dibujo, código sin hardware, inventario visual apagado | El estudiante puede liderar |
| Amarillo | USB, insertar shield, sensores de baja potencia, servo | Adulto presente y revisión antes de energizar |
| Rojo | 18650, cargador, VIN/VOUT, driver, motores, cableado de potencia | Adulto ejecuta o guía mano a mano |

## Antes de energizar

- Robot sobre base estable.
- Tornillos o herramientas fuera de las placas.
- Conectores alineados.
- Polaridad revisada dos veces.
- Ningún cable en ruedas o engranajes.
- Programa esperado identificado.
- Interruptor accesible.
- Persona y objetos fuera de la trayectoria.

## Durante movimiento

Cabello, cordones y ropa suelta lejos de ruedas. No detener ruedas con la mano. Empezar con baja velocidad, espacio despejado y una orden de parada conocida.

## Después

Apagar, esperar a que todo se detenga y tocar componentes solo si no hay señales de calor anormal. Guardar celdas según las instrucciones verificadas de su fabricante, nunca sueltas con metal.

## Privacidad y red

No publicar contraseña Wi-Fi, dirección externa, ubicación o identificadores personales en Git. Usar ejemplos como `MI_RED` y archivos de secretos excluidos cuando llegue el bloque IoT.

## Responsabilidades

El estudiante observa, predice, programa, mide y explica. El adulto valida alimentación, manipula celdas y decide si una pieza es segura. Preguntar o detenerse es parte del método científico.
