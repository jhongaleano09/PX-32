# Experimentos aislados

Este directorio recibirá protocolos reutilizables que prueban un solo subsistema sin convertirlos en una lección completa.

## Orden de aceptación

1. Cableado comparado con el mapa canónico y sistema apagado.
2. Programa mínimo.
3. Datos visibles en Serial cuando aplique.
4. Tres repeticiones.
5. Una variable modificada.
6. Criterio explícito de aprobado/no aprobado.

Los primeros experimentos están integrados en las lecciones 01-08. Se extraerán aquí cuando se reutilicen en bloques posteriores.
